# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Summary

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of background or identity. We expect contributors to
behave professionally and respectfully in issues, pull requests, discussions
and any other project space.

## Reporting

If you witness or experience behavior that violates this code, please report
it privately to the maintainers via the contact listed in
[SECURITY.md](SECURITY.md). All reports will be reviewed and handled
confidentially.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code. They may
remove, edit or reject comments, commits, code, issues and other contributions
that are not aligned with this Code of Conduct, and will communicate reasons
for moderation decisions when appropriate.
